# SistemaControleContatos

Este repositório contém um sistema de gerenciamento de contatos desenvolvido com .NET, permitindo a adição, edição, exclusão e visualização de contatos.

## Tecnologias Utilizadas

- **Backend**: C# com .NET
- **Banco de Dados**: (Informar a tecnologia de banco de dados utilizada, como SQL Server ou SQLite, etc.)

## Funcionalidades

- **Cadastro de Contatos**: Permite adicionar novos contatos ao sistema.
- **Edição de Contatos**: Facilita a atualização das informações dos contatos existentes.
- **Exclusão de Contatos**: Possibilita a remoção de contatos do sistema.
- **Visualização de Contatos**: Exibe uma lista dos contatos cadastrados.

## Estrutura do Projeto

A estrutura do repositório é a seguinte:

- **ControleDeContatos.sln**: Arquivo de solução do Visual Studio, que agrupa os projetos do sistema.
- **ControleDeContatos/**: Pasta que contém o código-fonte do projeto.
- **.vs/**: Pasta gerada pelo Visual Studio para armazenar configurações locais.
